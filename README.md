A monologue of about 100 words (104 words, 566 characters) spoken by a fantasy villain who is secretly just very tired, written by a program to `/output/entry.txt`. The tiredness lives in the rhythm and the small deflections — a hero count he stopped keeping, a scheme whose order he forgot, ravens that ate the list — never in a plain statement that he is weary. Node 22, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The monologue

> Welcome, hero. Number forty-seven this week — I stopped counting after the one with the lute. The torchlight, the dramatic entrance, the speech about justice: I have the whole thing memorised, and so does the dungeon. My scheme, since you ask, is the same as last Tuesday's: the eclipse, the crown, the — no, wait, the crown comes after the eclipse, I wrote it down somewhere. The ravens ate the list. Sit down. There is stew. It is mostly turnip. We can do the duel after, or not at all; the prophecy never specified a timetable, and neither, if I am honest, did I.
